# AI-Powered Cyberforensics Tool

A comprehensive digital forensic analysis platform powered by AI to assist investigators in analyzing suspicious files, logs, and building evidence timelines.

## Features

- **File Analysis**: Scan suspicious files with ML-based detection and YARA rules
- **Log Analysis**: Parse and detect anomalies in various log formats
- **Timeline Creation**: Build chronological event timelines from multiple evidence sources
- **Case Management**: Organize investigations with proper evidence handling
- **Web Interface**: User-friendly interface to access all tool capabilities

## Installation

```bash
# Clone the repository
git clone https://github.com/cynti10/AI-Cyberforensics-Tool.git
cd AI-Cyberforensics-Tool

# Install dependencies
pip install -r requirements.txt
```
